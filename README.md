# Banco de vozes SaCo

Uma página estática para uma escolha de voz: nove candidatas em português de Portugal a dizer os
mesmos excertos, com as medições e a proveniência de cada uma.

Abrir: https://mariocosttaa.github.io/saco-banco-de-vozes/

## Proveniência

Todo o áudio de referência sai de corpora de fala com licença CC0, em que quem gravou cedeu a voz
para este tipo de uso:

- **Common Voice**, português, sotaque de Portugal, CC0-1.0
- **Tugão 1.0**, um locutor, condições de estúdio, CC0-1.0
- Uma voz de máquina do Piper, MIT, que serve de controlo

Nenhuma referência sai de áudio apanhado na internet, e nenhuma pessoa identificável é imitada
sem ter cedido a voz para isso.

O texto dos excertos vem da documentação da plataforma SaCo e está classificado como Informação
Pública.
